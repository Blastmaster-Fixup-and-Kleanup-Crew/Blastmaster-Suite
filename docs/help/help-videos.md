# Blastmaster Suite Help Videos

The Help Video library complements the written Help Topics with short, screen-recorded demonstrations.

## Video Library

The planned series contains 16 videos covering the suite, installation, all four applications, troubleshooting-related workflows, editions, and file formats.

See the [complete video catalog](../help-videos/VIDEO_CATALOG.md) for the full list and production status.

## In-Application Availability

The Help Topics window can display this page even when the optional MP4 files are not installed. When rendered videos are packaged with a release, use the catalog's filenames and keep the video version aligned with the application build.

## Video Standards

- Daniel (UK) TTSDEmo narration.
- No presenter, face, webcam, or avatar.
- 16:9, 1920x1080 target.
- Actual Blastmaster Suite screens only.
- Cursor emphasis and readable menu/dialog close-ups.
- Do not demonstrate features that are not present in the current build.

## Written Help

For step-by-step reference, return to the Help Topics list and choose the application-specific topic. Written help remains the authoritative reference when a video has not yet been rendered for a release.
