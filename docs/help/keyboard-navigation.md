# Keyboard and Navigation

Blastmaster Suite uses conventional desktop application navigation.

## Menus

Press Alt to move into the menu bar when supported by the active platform and build.

Use arrow keys to move through menus.

Press Enter to activate a selected command.

Press Escape to close an open menu.

## Text Editing

Use the standard keyboard shortcuts provided by the current application for editing and navigation.

## Dialogs

Tab moves between controls.

Shift+Tab moves backward.

Arrow keys change selections in list controls where supported.

Enter activates the default dialog action.

Escape closes the dialog or cancels the current operation when supported.

## Accessibility

Use the operating system's keyboard navigation and accessibility features when needed.
