# Common Commands Reference

This page summarizes commands that appear throughout Blastmaster Suite.

## File

- New — Create a new document or project.
- Open — Open an existing file.
- Close — Close the current file.
- Save — Save changes.
- Save As — Save with a different name or location.
- Print Preview — Preview printed output.
- Print — Print the current document.

## Edit

- Undo — Reverse the most recent supported action.
- Repeat/Redo — Repeat or restore an action where supported.
- Cut — Remove selected content and place it on the clipboard.
- Copy — Copy selected content.
- Paste — Insert clipboard contents.
- Find — Search for content.
- Replace — Search for and replace content.
- Select All — Select all relevant content.

## View

View commands change the way the current document, worksheet, presentation, or database is displayed.

## Help

Help Topics opens the help system.

About displays application and version information.
