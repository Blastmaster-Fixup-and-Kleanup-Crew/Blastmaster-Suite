# Uninstalling Blastmaster Suite

Use the Blastmaster Suite uninstaller to remove the installed suite.

## Before Uninstalling

Save all open documents, workbooks, presentations, and databases.

Close all Blastmaster Suite applications.

Back up files that you want to keep.

## Uninstall

Launch the Blastmaster Suite uninstaller and follow its prompts.

Allow the process to complete before manually deleting remaining folders.

## After Uninstall

Verify that Blastmaster Suite applications are no longer present.

If the build installed file associations or shortcuts, verify that the Windows integration has been removed as expected.

Personal documents should be backed up independently of the program installation.
