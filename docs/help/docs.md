# Blastmaster Docs Help

Docs is the Blastmaster Suite word processor.

## Getting Started

Choose **File > New** to create a document.

Choose **File > Open** to open an existing `.dccx` document.

Choose **File > Save** to save changes.

Choose **File > Save As** to save a document under another name or location.

## Classic Docs workflow

### Create and organize a document
1. Choose **File > New** and begin with the insertion point in the document area.
2. Use **File > Save** regularly. For a new document, Save opens the Save As flow.
3. Use **File > Save As** to create a separate copy. Keep the `.dccx` extension for the native format.

### Select and revise text
- Select text before applying character formatting.
- Use **Edit > Find** to locate text and **Edit > Replace** to revise repeated wording when those commands are available in your build.
- Use Undo immediately after an unintended edit. Save a checkpoint before large structural changes.
- If a dialog is cancelled, confirm that the document remains unchanged before continuing.

### Page layout and tables
Use page setup before final printing. Check margins, orientation, page breaks, and page numbering in Print Preview. For tables, select the intended cell, row, column, or table before invoking a table command; verify the result before saving.

### Troubleshooting
- **Formatting changes unexpectedly:** select the affected text and inspect its font and paragraph settings.
- **The printout differs from the page view:** use Print Preview and verify paper size and margins.
- **A save fails:** use Save As to a writable local folder and confirm the file can be reopened.

Commands described in the menus may be placeholders in a particular build. Treat a command as supported only when it performs the described operation successfully.
