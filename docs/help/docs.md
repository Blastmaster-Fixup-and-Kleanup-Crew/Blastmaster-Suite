# Blastmaster Docs Help

Docs is the Blastmaster Suite word processor.

## Getting Started

Choose **File > New** to create a document.

Choose **File > Open** to open an existing `.dccx` document.

Choose **File > Save** to save changes.

Choose **File > Save As** to save a document under another name or location.

## Editing

The Edit commands include:

- Undo
- Repeat
- Cut
- Copy
- Paste
- Paste Special
- Clear
- Select All
- Find
- Replace
- Go To
- AutoText

## Formatting

The Format menu provides tools for:

- Fonts
- Paragraphs
- Tabs
- Borders and Shading
- Columns
- Drop Caps
- Bullets and Numbering
- Change Case
- Heading Numbering
- Styles
- AutoFormat
- Themes

## Inserting Content

The Insert menu supports document elements such as:

- Breaks
- Page Numbers
- Date and Time
- Fields
- Symbols
- Form Fields
- Comments
- Footnotes
- Captions
- Cross-references
- Indexes and Tables
- Pictures
- Objects
- Files

## Tables

The Table commands allow you to insert tables and work with cells, rows, columns, and complete tables.

Available operations include:

- Select Cell
- Select Row
- Select Column
- Select Table
- Split Cells
- Split Table
- Table Properties
- Convert Text to Table

## View

Docs provides Normal, Page Layout, Outline, and Master Document views.

Additional display commands include Toolbars, Ruler, Header and Footer, Footnotes, Full Screen, and Zoom.

## Tools

Productivity and review tools include:

- Spelling
- Grammar
- Thesaurus
- Hyphenation
- Language
- Word Count
- AutoCorrect
- Mail Merge
- Envelopes and Labels
- Protect Document
- Revisions
- Macro
- Customize
- Options

## Printing

Use **File > Page Setup** to configure the page.

Use **File > Print Preview** to inspect output.

Use **File > Print** to send the document to the printer.

## Windows

The Window menu provides New Window, Arrange All, Split, and Open Document Files.

## Help

The Help menu provides **Help Topics** and **About Blastmaster Docs**.

Help Topics opens the application-specific Blastmaster Docs help library.
