# Blastmaster Suite File Formats

## Native Formats

| Application | Native extension |
|---|---|
| Docs | `.dccx` |
| Workbooks | `.wkbx` |
| Presentations | `.prex` |
| Databases | `.dbbx` |

## Choosing a Format

Use the application's native format when you need to preserve the full Blastmaster Suite editing experience.

Use Export when an application provides a supported interchange format and the receiving application requires it.

## File Safety

Keep backups of important files.

Do not rename a file extension simply to make it open in another application. Use an actual export function when one is available.
