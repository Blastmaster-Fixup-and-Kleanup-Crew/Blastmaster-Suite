# Product Keys and Editions

Blastmaster Suite uses product keys to determine which edition is installed.

## Standard

The Standard edition provides:

- Docs
- Workbooks
- Presentations

## Professional

The Professional edition provides:

- Docs
- Workbooks
- Presentations
- Databases

## Entering a Key

Enter the product key in the Setup wizard's Product Key page.

Type each character carefully.

Do not alter the key format.

## If a Key Is Rejected

Check:

1. Every character.
2. The number of groups.
3. That no extra spaces were entered.
4. That the key belongs to the intended edition.
5. That the installer is the expected Blastmaster Suite build.

Never publish or share a private product key in screenshots or support logs.
