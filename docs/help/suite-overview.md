# Blastmaster Suite Overview

Blastmaster Suite is a classic office productivity suite.

## Applications

### Docs

A word processor for creating and formatting documents.

Native file extension: `.dccx`.

### Workbooks

A spreadsheet application for worksheets, calculations, and organized tabular data.

Native file extension: `.wkbx`.

### Presentations

A presentation application for creating and presenting slides.

Native file extension: `.prex`.

### Databases

A database application for tables, queries, forms, reports, and relationships.

Native file extension: `.dbbx`.

Databases is part of the Professional edition.

## Editions

The Standard edition contains Docs, Workbooks, and Presentations.

The Professional edition contains Docs, Workbooks, Presentations, and Databases.

## Getting Started

1. Install Blastmaster Suite.
2. Enter a valid product key.
3. Choose the destination folder.
4. Start the application you need.
5. Create a new file or open an existing file.
6. Save your work using the application's native format.

## Classic Interface

The applications use a traditional menu-bar and toolbar workflow. Commands are generally grouped under File, Edit, View, Insert, Format, Tools, Window, and Help, with application-specific menus added where appropriate.
