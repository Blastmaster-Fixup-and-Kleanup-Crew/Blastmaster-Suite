# Troubleshooting Blastmaster Suite

## Setup will not accept my product key

Verify every character and make sure the key is intended for the edition you want.

If the problem continues, verify that you are using the correct installer build.

## An application will not start

Check that installation completed successfully.

Try launching the application again after closing other Blastmaster Suite processes.

If the problem began after modifying program files, reinstall the current build.

## A file will not open

Confirm that the file has the correct native extension.

Make sure the file belongs to the corresponding application.

Restore the file from a backup if it may be damaged.

## Changes were lost

Check whether the file was saved.

Look for another copy created with Save As.

Save frequently when working on important material.

## Printing does not look correct

Use Print Preview first.

Check page setup, margins, orientation, and printer selection.

## Database results are unexpected

Review the table data, query criteria, and relationships.

Use Design View to inspect object configuration.

## Getting help

Record the application name, version/build, exact error message, and the steps that produced the problem.

Avoid including private product keys or personal documents in support material.
