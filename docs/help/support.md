# Help and Support

## In-Application Help

Use the Help menu and Help Topics where available.

## Reporting a Problem

A useful bug report includes:

- Application name
- Suite edition
- Version/build
- Operating system
- Exact steps to reproduce the problem
- Expected result
- Actual result
- Exact error text
- Relevant log information

## Screenshots

Screenshots should show only the information needed to explain the problem.

Do not include product keys, passwords, private documents, or other sensitive information.

## Reproducing Problems

Try to reproduce the issue with a new test file.

This helps determine whether the problem is application-wide or specific to one file.
