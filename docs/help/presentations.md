# Blastmaster Presentations Help

Presentations is the slide-creation application in Blastmaster Suite.

## Getting Started

Choose **File > New** to create a presentation.

Choose **File > Open** to open an existing `.prex` presentation.

Choose **File > Save** to save changes.

Use **Save As** to create another copy or save to another location.

## Slides

Create and organize slides using the available slide commands.

Select a slide before editing its content.

Use formatting commands to control text, alignment, bullets, and other presentation elements.

## Insert

Use Insert commands to add supported objects and content to a slide.

## Design

Use the available design and template commands to maintain a consistent appearance across the presentation.

## Slide Show

Use the Slide Show commands to start and control a presentation.

Before presenting, review every slide in the available presentation views.

## Printing

Use print and page-setup commands when printed copies are required.

## Saving

Save regularly while working.

Use the native `.prex` format when you want to preserve the presentation in Blastmaster's native format.
