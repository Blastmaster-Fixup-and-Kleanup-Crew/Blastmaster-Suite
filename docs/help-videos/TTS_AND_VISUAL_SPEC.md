# TTS and Visual Production Specification

## Voice

Use **Daniel (UK)** in TTSDEmo.

Recommended presentation:
- Natural/default pitch
- Normal conversational speed
- No character acting
- No face or avatar
- No voice effects unless required to correct a recording

Before publishing, listen for pronunciation of:
- Blastmaster
- Blastmaster Suite
- Docs
- Workbooks
- Presentations
- Databases
- CMake
- Qt
- SQLite
- DCCX
- WKBX
- PREX
- DBBX

If the TTS engine pronounces an acronym poorly, spell it phonetically in the TTS input while keeping the on-screen text unchanged.

## Visual rules

Every video should show the actual application rather than a generic office-suite mock-up.

Use:
1. 3–5 second title card.
2. Direct screen capture.
3. Cursor highlight when an important command is selected.
4. Zoomed crop only when a menu or dialog is difficult to read.
5. Short chapter card when moving to a new major topic.
6. 3–5 second end card.

Do not show:
- A human face
- A webcam
- A presenter avatar
- Unrelated stock footage
- Features not present in the current build
